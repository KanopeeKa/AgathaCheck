Post–Sprint 4.3 assessment: progress, gaps, and recommended direction.  
Companion to `docs/quality/scorecard.md` and `docs/quality/bdd-journey-matrix.md`.

## Executive summary

Sprints **1–4 are complete on `main`**. Sprint 4.3 delivered the **50% BDD gate (81/161 scenarios)**, **79 Playwright tests**, and a living journey matrix. Unit-test depth and CI security gates are strong.

**Remaining gaps:** BDD gate was not yet enforced in CI; regulation (GDPR export/delete) lags documentation; org-operator/adoption journeys have **0%** Playwright coverage; several hand-written files exceed **500 lines**; Cursor rules assumed trunk-only single-agent workflow.

**Actions from this review (Sprint 5.1):** integration-branch policy codified; file-size CI gate with grandfather ratchet; BDD coverage wired into PR CI; Sprint 5–7 plan with parallel-agent ownership map.

## Parallel-agent lessons (Sprint 4.3)

**Worked:** integration branch → single PR; file-owned waves; cherry-pick recovery.

**Failed again:** commits on wrong agent branches (auth/pet on vet branch; coverage gate orphaned).

**Mitigations (now policy):** integration branch default for multi-agent requests; directory ownership map; foundation agent serialises `api.ts`; verify branch tip before spawning next agent.
