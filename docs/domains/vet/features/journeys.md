# Veterinarian journeys

User-facing flows for managing vet contacts in AgathaTrack.

## Create veterinarian

Guardians add a vet from the veterinarian list (app bar icon or navigation). Minimum required field is name; phone, email, address, and notes are optional.

## View and link pets

The vet list shows cards with linked pet names. Detail view surfaces contact fields and which pets use this vet.

## Edit and delete

Phone and other fields can be updated. Deletion requires confirmation; cancel keeps the vet in the list.
