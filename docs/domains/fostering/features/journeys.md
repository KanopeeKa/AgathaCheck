# Fostering journeys

Custody **transfer workflows** in AgathaTrack (code still under `organization/` feature folder).

## Foster onboarding

Foster parents accept invitations, complete onboarding, and gain access to assigned pets.

Full flow: [j1-foster-onboarding.md](../changes/j1-foster-onboarding.md)

## Foster self-management

Active fosterers view and update day-to-day care for placed pets (experience program Phase 4).

## Adoption and return

Placements move through the [foster placement lifecycle](foster-placement-lifecycle.md) — adoption confirmation, conditions, and return-to-org paths.

## Org-to-org transfer

Connected organisations transfer guardianship per custody model — see [g0-contract-pack.md](g0-contract-pack.md).
